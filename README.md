# CityTrail

App móvil para turistas desarrollada con C# y .NET MAUI.

## Objetivo
Proyecto de aprendizaje y portfolio. Incluirá puntos de interés,
tours, restaurantes, opiniones y un asistente con IA.

## Stack
- .NET MAUI
- MVVM (CommunityToolkit.Mvvm)

## Estado
En desarrollo. Fase 0 (Instalación MVVM y navegación entre páginas) completada.
